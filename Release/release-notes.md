A floating dock and live wallpaper for Windows, made by Yusuf Yunus.

## Install

Download `Harbor-Setup-1.3.1.exe` below and run it. It needs no admin rights and nothing else installed.

The installer isn't code signed, so Windows may show "Windows protected your PC". Choose **More info**, then **Run anyway**.

## In this version

- Maximized windows fill the whole screen again when Harbor hides the Windows taskbar
- Clicking a minimized app in the dock brings it back reliably
