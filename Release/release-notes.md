A floating dock and live wallpaper for Windows, made by Yusuf Yunus.

## Install

Download `Harbor-Setup-1.1.0.exe` below and run it. It needs no admin rights and nothing else installed.

The installer isn't code signed, so Windows may show "Windows protected your PC". Choose **More info**, then **Run anyway**.

## In this version

- A dock on every screen, sized correctly even when your screens are scaled differently
- A clock and calendar at the end of the dock
- A brightness slider for each screen in the quick panel
- A fix for the wallpaper only covering part of a second screen
